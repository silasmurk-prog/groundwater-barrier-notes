地下水与污染物迁移

3.1 场地概念模型

含水层是能储存、传输地下水的地层；弱透水层传水慢，但不必然完全阻断溶质。污染羽是污染物在地下水中形成的空间分布区。

先画平面和剖面：污染源、流向、水位、地层、监测井、污染羽深度、下游保护对象。裂隙、砂透镜体和季节水位变化都可能改变迁移路径。

关联文献：R07 R11 R17

3.2 重金属：先问形态，再选材料

总浓度之外，还需记录金属价态、溶解/颗粒状态、pH、氧化还原条件和共存离子。Cr(VI)、Pb²⁺、Cd²⁺不能按同一种污染物处理。

金属元素不能被“生物降解消失”。处理通常改变价态、吸附位置或固液分配；还需关注解吸、再溶出与二次释放。

关联文献：R10 R12 R16

3.3 四类迁移过程，各回答一个问题

过程直观理解对设计的意义
对流随地下水流动被带走。决定到达时间、流向与 PRB 停留时间。
分子扩散由浓度梯度引起净迁移，水流很慢时仍存在。低渗透墙中不能因 K 很小就忽略扩散。
机械弥散不同流路和局部速度让污染带展开。决定污染羽宽度与捕获余量；需区分纵向、横向。
吸附与反应转移到固相、离子交换、还原或沉淀等。决定材料需求与处理能力；吸附容量有限。

3.4 最先掌握的三组公式

q = −K∇h；　v = q / neq：达西通量 [m/d]；K：水力传导系数 [m/d]；h：水头 [m]；nₑ：有效孔隙率 [无量纲]；v：平均孔隙水流速 [m/d]。

q 按整个截面积计算；水实际通过孔隙，所以不能把 q 直接当成污染物随水运动的速度。多维模型中 K 可以是张量，流向由水头场决定。

Rd ∂C/∂t = D ∂²C/∂x² − v ∂C/∂x一维、饱和、常参数、线性瞬时平衡吸附、无净反应源汇的入门形式。D [m²/d] 是水动力弥散系数，C 是溶解相浓度。

加入化学反应、非平衡吸附或空间变参数时，应回到质量守恒形式。尤其不能直接为“总重金属”加上未经验证的一阶降解项。

S = KdC；　Rd = 1 + ρbKd / nS [mg/kg]；C [mg/L]；Kᵈ [L/kg]；ρᵦ [kg/L，干土质量/总体积]；n 是本简化饱和模型的孔隙率。使用同一体积基准并统一单位。

阻滞表示迁移被延迟，不表示污染物永久消失。线性 Kd 适用于有限浓度范围；Langmuir 等温式表示有限容量，Freundlich 是经验非线性关系，均需要实验拟合。

关联文献：R01 R10 R17 R20

掌握标准：能解释为什么“流速慢”“浓度低”“累计迁移质量少”是三个不同结论，并能正确换算 m/s 与 m/d（乘以 86400）。

04

屏障类型与选型

先按“怎么控制污染”区分，再讨论材料、施工方式和空间布置。不能把土–膨润土、连续墙和漏斗–门当作同一层级的类别。

类别工作原理与常见形式优先考虑什么局限与失效路径
A · 低渗透阻隔型减少穿过屏障的水流与溶质通量。包括土–膨润土（SB）、水泥–膨润土（CB）、土–水泥–膨润土墙及膜复合屏障。低渗透、化学相容性、接缝与嵌入深度；有时还利用吸附阻滞。仍可能扩散、裂缝渗漏、端部绕流或底部绕流；围封还需处理内部水量。
B · 可渗透反应型（PRB）让地下水穿过反应介质，通过吸附、交换、还原或沉淀降低目标污染物浓度。污染羽捕获、反应停留时间、材料容量与长期透水性。材料饱和、钝化、孔隙堵塞或水流旁路。
C · 组合型低渗透段负责导流或围控，反应段负责处理；漏斗–门是代表性构型。导流与处理必须联合设计，校核门区流量和停留时间。门区流速上升可能缩短接触时间；墙端和门墙连接处需检查。

设计公式与计算示例

先弄清水怎么流，再估计需要多长接触时间、多少反应容量，最后检验长期突破和水力变化。下式是学习与建立基准模型的入口，不是已经完成的工程设计。

符号统一：K＝渗透系数，Kd＝固液分配系数，q＝达西通量，v＝孔隙水流速。不同论文会重复使用同一字母；每次代入前先核对定义。缺少场地参数时不输出“推荐墙厚”。

1 · 从流速、反应速率得到接触时间和厚度

原式＋教学重写
|q| = K |i|　　v = |q| / nₑ
treq = ln(C₀/Ctarget) / keff
Lkin = v treq

K、q、v使用相同长度/时间单位；i为水力梯度，nₑ为有效孔隙率，keff是经试验拟合的一阶表观速率常数（时间⁻¹）。在R32式(10)–(11)中，keff=λρₘ；不要把这一单位不同的λ当作keff直接代入。

适用条件：稳态、近似均匀的一维流动及可用一阶动力学描述的有效反应阶段。反应衰减、旁流、堵塞或容量耗尽需要进一步建模。流速应取墙体内实际流速，不能始终沿用建墙前含水层流速。

自拟算例：若v=0.05 m/d，keff=0.5 d⁻¹，要求浓度降至进水的1/10，则t≈4.61 d、L≈0.23 m。这只是理想动力学尺度，未包含容量、非均质和施工约束。

流速依据：USGS Heath，正文p.25。反应时间依据：R32 PDF p.8，式(10)–(11)。L=vt为本站的接触时间关系；没有把它冒充R32式(12)。

2 · 去除率与突破曲线：先比较同一口径

论文原式的百分数表达
η = (Cin − Cout) / Cin × 100%
突破曲线：Cout(t) / Cin 对 t

C必须同单位、同分析对象；总铬和六价铬不能混算。变进水时还要考虑水流的时间延迟。某个时刻去除率很高，不代表累计截留量大或服役期长。突破时间需预先定义判据，例如保护点目标浓度，而非任意指定百分比。

依据：R33 PDF p.4，式(1)（原式为比例）；突破定义对照R34 PDF p.4及图2。

3 · 吸附容量：从试验测量到可用容量

论文原式，统一记号
qₑ = (C₀ − Cₑ)V / m
qₑ = qmaxKLCₑ / (1 + KLCₑ)

第一式是批量质量平衡：C取mg/L、V取L、m取g，得到qₑ为mg/g。必须排除容器损失等非材料作用。第二式是Langmuir等温关系，KL为L/mg、qmax为mg/g；仅在实验适用范围使用，不能默认多金属竞争也服从单组分式。

建模要区分批量平衡容量、柱试验动态容量与长期有效容量。若发生沉淀，差值法记录的是从溶液中移除的量，单凭该式不能证明全部属于表面吸附。

质量平衡：R41 PDF p.5，式(1)。Langmuir式由R39 期刊p.71 / PDF p.3，式(2)代数整理；不沿用R41式(4)中未明确的容量记号。

4 · 水力性能：PRB与隔离墙的目标不同

论文原式
Kᵣ = Kfinal / Kinitial
变水头试验：K = aL ln(h₁/h₂) / (AΔt)

Kᵣ无量纲；a为测压管面积，A为试样截面积，L为试样长度，h₁、h₂为开始与结束的水头差，Δt为历时。面积、长度和时间采用统一单位；需满足试样饱和、适用达西流等试验前提。

PRB通常需要维持足够通水能力，隔离墙则需要较低渗透性。Kᵣ接近1只代表“相对稳定”，不能证明K的绝对值符合设计要求。实验滤饼、填充柱和实际墙体不能直接等同。

比值：R34 PDF p.4，式(1)。变水头：R44 期刊p.106 / PDF p.4，式(5)。

5 · 迟滞：污染物走得慢，不等于被永久去除

原式记号统一
R = 1 + ρbKd / n

ρb为干容重，n为孔隙率。若ρb用kg/m³，Kd用m³/kg，R无量纲。适用于饱和单孔隙域、线性瞬时平衡吸附等假设；非线性、不可逆反应及动力学限制需要修改模型。

R较大可推迟突破，但源停止后仍可能解吸。R34的R_f使用污染前锋速度定义，且水流速度口径为Q/A，不可与本式数值直接互换。

依据：R42 PDF p.2，式(2)。本站将原文分配系数K写为Kd，干密度ρd写为ρb，孔隙率η写为n。

6 · 质量负荷和容量寿命：补上去除率没告诉你的事

本站质量守恒推导，非某篇原式
Mremoved = ∫ Q(t)[Cin(t) − Cout(t)]dt
Tcap ≈ mmedia qusable / [Q(Cin − Cout)]

第一式针对水量进出平衡、已考虑停留时间及水相储量变化的控制体；无法忽略储量时必须额外计入。Q用L/d、C用mg/L，积分得到mg。第二式进一步假设流量、浓度差稳定且可用容量均匀利用；分子与分母须统一质量单位。

Tcap只是容量约束下的理想估算，不覆盖水力失效、反应钝化、旁流和共存物质竞争。局部过早突破可能使实际服务期远短于该数值。实际模型还需考虑扩散等通量，不能始终用qC代表全部传质。

推导起点：R41式(1)的质量平衡思想；为何必须同时考虑水力与突破，见R34。此处未虚构任何论文公式编号。

7.1 浓度、通量与捕获

浓度：指定点和时刻的 C；质量通量：单位面积单位时间通过的质量；捕获：污染流是否进入控制区域。PRB 内出水低浓度，仍可能伴随墙外旁路泄漏。

溶质通量可写为 J = qC − nD∇C；跨截面质量流率为对法向通量的面积积分。多维、变参数模型需保持符号与单位一致。

7.2 首次超限时间

先指定保护点或控制截面、目标物种、阈值 Climit 与评价期。再定义 Tb = inf{t : Ccontrol(t) ≥ Climit}。

只在模拟终点仍未超限时，应写“Tb 大于本次评价期”，不能称为无限寿命。相对浓度 0.1 只是可能的实验判据，不是通用达标标准。

方案优化与团队协作

优化的前提是可验证的性能模型。算法负责搜索方案，评价模型负责判断方案是否可信。

  1. 定义目标与边界：明确目标金属/形态、保护位置、评价期、场地范围和施工条件。
  2. 构建基准：保留“无屏障”与一组简单可行屏障方案，作为对照。
  3. 筛选类型与材料：排除反应条件或施工条件明显不适合的组合。
  4. 验证前向模型：先可靠地回答“给定一个方案，会怎样”。
  5. 做参数敏感性分析：分清场地不确定参数与设计变量，识别关键影响量。
  6. 在约束下搜索：少量变量先做参数扫描；复杂后再选择 GA、PSO 或多目标算法等工具。
  7. 复算与复核：用独立/高精度模型复算候选优选方案，检查场景变化后的可靠性。
